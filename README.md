# צַיָּד הַנִּקּוּד

משחק דפדפן ללימוד ניקוד עברי. המטוס שלכם טס מתחת לאותיות הנופלות — תפסו את האות בעלת הניקוד הנכון!

## איך משחקים

1. לוחצים על **"התחל משחק"**.
2. שומעים הברה בעברית (עיצור + ניקוד, למשל "בַ").
3. שתי אותיות נופלות מלמעלה — שתיהן עם אותו עיצור אך עם ניקוד שונה.
4. מזיזים את המטוס עם העכבר.
5. תופסים את האות עם הניקוד שנשמע.
6. טעות או אות מטרה שמגיעה לקרקע = איבוד חיים.
7. המשחק נגמר כשנגמרים החיים.

## הפעלה

### אופציה 1 — פתיחה ישירה

פותחים את הקובץ `index.html` בדפדפן (לחיצה כפולה).

### אופציה 2 — שרת מקומי (מומלץ)

מריצים בטרמינל מתוך תיקיית המשחק:

```
python -m http.server 8000
```

ואז גולשים אל `http://localhost:8000`.

## בקרות

| פעולה | מקש |
|------|------|
| הזזת המטוס | עכבר |
| השמעה חוזרת | לחיצה על הרמקול / רווח |
| השהיה | P או Escape |

## שלבי המשחק

- **שלב 1** — פַתָּח מול חִירִיק (a / i).
- **שלב 2** — מתווספים צֵירֵי וחוֹלָם.
- **שלב 3** — מתווסף שׁוּרוּק, המהירות עולה.
- **שלב 4+** — עיצורים משתנים ומהירות עולה עוד.

## דרישות דפדפן

- דפדפן מודרני (Chrome, Edge, Safari, Firefox).
- לקול של ההברה — צריך קול עברי מותקן במערכת (Web Speech API). ברוב המערכות החדשות (macOS, Windows 10+, Android, iOS) זה זמין.
- אם אין קול עברי — במקום שמע יופיע על המסך **שם הניקוד** ככלי עזר.

## שמירת שיא

השיא הגבוה ביותר נשמר אוטומטית ב-`localStorage` של הדפדפן.
